程序 = 数据 + 算法。这一篇讲数据怎么存。

## 变量是什么

变量可以理解为「一块有名字的内存」，使用时有三要素：**类型、名字、值**。

```c
int age = 18;      // 整型变量
double score = 92.5; // 双精度浮点变量
char grade = 'A';    // 字符变量，注意是单引号
```

变量必须先声明后使用；名字区分大小写；不能以数字开头，不能是关键字。

## 基本数据类型

| 类型 | 典型字节数 | 取值范围（典型） | 说明 |
| --- | --- | --- | --- |
| `char` | 1 | -128 ~ 127 | 存字符/小整数 |
| `short` | 2 | -32768 ~ 32767 | 短整型 |
| `int` | 4 | 约 ±21 亿 | 最常用 |
| `long` | 4 或 8 | 视平台 | 长整型 |
| `long long` | 8 | 约 ±9.2×10^18 | 大整数 |
| `float` | 4 | 约 ±3.4×10^38（6~7 位有效数字） | 单精度 |
| `double` | 8 | 约 ±1.8×10^308（15~16 位有效数字） | 双精度，推荐 |

`unsigned` 前缀表示无符号，只能表示非负数，正数范围翻倍。

```c
unsigned int u = 4000000000u; // 合法
```

**用 sizeof 实测**（不同平台可能不同，别死记）：

```c
#include <stdio.h>

int main(void) {
    printf("char: %zu\n", sizeof(char));
    printf("int: %zu\n", sizeof(int));
    printf("long: %zu\n", sizeof(long));
    printf("double: %zu\n", sizeof(double));
    printf("int 变量本身: %zu\n", sizeof(int));
    return 0;
}
```

## 整数溢出：最容易被忽略的问题

每种类型能表示的范围有限，超过范围会「回绕」：

```c
#include <stdio.h>

int main(void) {
    int max = 2147483647;   // int 的最大值
    printf("%d\n", max + 1); // 输出 -2147483648，而不是 2147483648
    return 0;
}
```

估算结果可能超出范围时，换 `long long`。这一点在做阶乘、斐波那契等题目时会踩坑。

## 字符与 ASCII

`char` 存的其实是字符对应的编码值（ASCII）：

```c
char c = 'A';
printf("%c %d\n", c, c);  // 输出 A 65
```

常用值：`'A'`=65，`'a'`=97，`'0'`=48。大小写转换可以用 `'a' - 'A'` 的差值（32）。

## 转义字符

| 转义 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠本身 |
| `\'` `\"` | 单/双引号 |
| `\0` | 空字符，字符串结束标志 |

## 常量

```c
#define PI 3.14159          // 预处理宏，无类型
const double E = 2.71828;   // const 常量，有类型、更安全
```

推荐优先用 `const`，宏在复杂场景下容易出问题（见第十四篇）。

## 类型转换

```c
int a = 5, b = 2;
double r1 = a / b;              // 2.000000，整数除法先算完再转
double r2 = (double)a / b;      // 2.500000，显式转换
int pi = 3.99;                  // 隐式截断，pi = 3，不是四舍五入
```

记住两句话：**整数除法会丢小数**；**浮点转整数是截断不是四舍五入**。

3. 计算 `int` 除以 `int` 得到小数，验证两种写法的差别。
