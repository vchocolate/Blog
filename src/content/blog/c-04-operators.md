运算符是程序的「动词」。C 的运算符不多，但细节不少。

## 算术运算符

`+ - * / %`，其中有两个高频坑：

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", 5 / 2);      // 2，整数除法丢掉小数
    printf("%.1f\n", 5.0 / 2);  // 2.5，只要有一个浮点数就是浮点除法
    printf("%d\n", 5 % 2);      // 1，取余，两边必须是整数
    printf("%d\n", -5 % 3);     // -2，负数取余结果符号取决于实现，别依赖
    return 0;
}
```

## 关系运算符与逻辑运算符

关系：`> >= < <= == !=`，结果是 `1`（真）或 `0`（假）。

逻辑：`&&`（与）、`||`（或）、`!`（非）。

**短路求值**很重要：

```c
int a = 0;
if (a != 0 && 10 / a > 1) {  // a 为 0 时右边不会执行，不会除零崩溃
    printf("不会走到这里\n");
}
```

`&&` 左边为假，右边直接不执行；`||` 左边为真，右边直接不执行。利用这一点可以做安全检查，但也不要写依赖副作用的怪代码。

## 自增自减

`i++` 与 `++i` 单独成句时效果一样，混在表达式里才要小心：

```c
int i = 5;
int a = i++;   // a = 5, i = 6（先用后加）
i = 5;
int b = ++i;   // b = 6, i = 6（先加后用）
```

实用建议：**不要在一条语句里对同一个变量既读又改**，比如 `i = i++ + ++i;`，这是未定义行为，不同编译器结果不同。

## 位运算

按位操作，处理二进制时很有用：

```c
unsigned char x = 0b00001111; // 15
printf("%d\n", x & 0b00000011); // 3，按位与，常用于「取某些位」
printf("%d\n", x | 0b11110000); // 255，按位或，常用于「置位」
printf("%d\n", x ^ 0b11111111); // 240，按位异或，常用于「翻转」
printf("%d\n", ~x & 0xFF);      // 240，按位取反
printf("%d\n", 1 << 4);         // 16，左移相当于乘 2 的幂
printf("%d\n", 32 >> 2);        // 8，右移相当于除 2 的幂
```

交换两个变量也可以不用临时变量（了解即可，工程上不推荐）：

```c
a ^= b; b ^= a; a ^= b;
```

## 复合赋值与条件运算符

```c
int s = 10;
s += 5;   // s = s + 5
s *= 2;   // s = s * 2

int max = (a > b) ? a : b;  // 三元运算符：条件 ? 真值 : 假值
```

## 优先级：别背，用括号

常见坑：

```c
int a = 1, b = 2, c = 3;
int r = a > b ? a : b > c ? b : c; // 嵌套三元，可读性差
if (a & 1 == 0) { }  // 错！== 优先级高于 &，实际是 a & (1==0)
if ((a & 1) == 0) { } // 对
```

原则：**拿不准就加括号**，可读性比少打两个字符重要。

## 易错点清单

- `=` 是赋值，`==` 才是判断相等（`if (a = 0)` 恒为假，编译器通常会警告）。
- 整数除法先截断再赋值。
- 浮点数不要直接用 `==` 比较，用差值小于一个极小值来判断。
- 自增自减不要在复杂表达式里混用。
