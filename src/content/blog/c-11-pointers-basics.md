指针是 C 语言的分水岭，也是说得最多「听不懂」的地方。这篇尽量把每一步都拆开。

## 从内存地址说起

变量存在内存里，每个字节有一个编号，叫**地址**。

```c
int a = 42;
```

假设 `a` 占的 4 个字节从地址 `0x7ffee0` 开始：

```text
地址:   0x7ffee0  0x7ffee1  0x7ffee2  0x7ffee3
内容:     42        0         0         0     （小端序）
```

`&a` 取出 a 的地址，`*p` 顺着地址找到那块内存。

## 指针变量

指针就是「存地址的变量」。

```c
int a = 42;
int *p = &a;    // p 的类型是 int*，指向 int

printf("%p\n", (void *)p);   // 打印地址
printf("%d\n", *p);          // 42，解引用，取出地址上的值

*p = 100;                    // 通过指针修改 a
printf("%d\n", a);           // 100
```

两个符号别搞混：

- `&`：取地址，`&a` 得到 a 的地址。
- `*`：解引用，`*p` 得到 p 指向的值。（声明时的 `*` 表示「这是指针类型」）

## 指针的类型很重要

```c
int *pi;      // 指向 int
double *pd;   // 指向 double
char *pc;     // 指向 char
```

类型决定了「解引用时读几个字节」和「指针 +1 走多远」：

```c
int a[3] = {10, 20, 30};
int *p = a;          // 数组名就是首元素地址
printf("%d\n", *(p + 1));   // 20，不是 11
```

`p + 1` 不是地址加 1 字节，而是加一个 `int` 的大小（4 字节），指针运算会自动按类型缩放。

## NULL 与野指针

```c
int *p = NULL;   // 空指针，明确不指向任何东西

if (p != NULL) {
    printf("%d\n", *p);   // 用前检查
}
```

危险写法：

```c
int *q;         // 未初始化！野指针，指向随机地址
*q = 5;         // 未定义行为，通常直接崩溃
```

规矩：**指针要么指向合法内存，要么赋 NULL，绝不裸奔**。

## 指针与数组

数组名在大多数表达式中等价于首元素地址：

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a;         // 等价于 &a[0]

// 下面几种写法等价
a[i] == *(a + i) == *(p + i) == p[i]
```

遍历的两种写法：

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", p[i]);     // 指针也能用下标
}

for (int *q = a; q < a + 5; q++) {
    printf("%d ", *q);       // 指针移动
}
```

**但数组不是指针**，两个关键区别：

```c
int a[5];
int *p = a;
printf("%zu\n", sizeof(a));   // 20，整个数组的大小
printf("%zu\n", sizeof(p));   // 8（64 位系统），一个指针的大小
// a = p;      // 错！数组名不能赋值
p = a + 1;     // 对，指针可以移动
```

## 指针与字符串

```c
const char *s = "hello";
printf("%c\n", *s);       // h
printf("%c\n", *(s + 1)); // e

// 遍历字符串
for (const char *q = s; *q != '\0'; q++) {
    putchar(*q);
}
```

字符串常量不可修改：`s[0] = 'H'` 会崩溃。要改就用字符数组。
